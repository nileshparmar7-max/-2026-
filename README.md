# યુવા સંમેલન 2026 — વટવા નગર

આ એક responsive static website છે, screenshotsમાં બતાવેલી Gujarati youth-conference styleને ધ્યાનમાં રાખીને બનાવેલી છે.

## ઝડપી ફેરફાર
`script.js`ની શરૂઆતમાં `EVENT` objectમાં:
- date
- time
- venue
- contacts

બદલો.

## Vercel પર deploy
1. આ folder GitHub repositoryમાં upload કરો.
2. Vercelમાં "Add New Project" પસંદ કરો.
3. GitHub repository પસંદ કરો.
4. Framework preset માટે "Other" અથવા static site રાખો.
5. Deploy કરો.

## નોંધ
Registration form હાલ demo modeમાં છે અને data server/databaseમાં save કરતું નથી. Real registration માટે backend / Google Sheets / Supabase / Firebase વગેરે જોડવું પડશે.
